SwiftDownload

Browser downloads

Cookies are sent only to SwiftDownload on this computer, only for the address being downloaded, and SwiftDownload never sends them to other servers.

Media detection

Detect these types
SwiftDownload needs access to websites to detect media.

If SwiftDownload is not reachable, the browser keeps downloading the file itself. Protected (DRM) and live streams are never downloaded. YouTube videos are not supported: YouTube's terms do not allow downloading them.
